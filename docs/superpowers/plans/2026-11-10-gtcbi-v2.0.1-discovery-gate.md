## 公共数据契约

新发现记录使用 discovery_schema="discovery-gate-v1"；model_version 保持 "2.0.1"。

| 键 | 类型与定义 |
| --- | --- |
| discovery_id | 非空字符串；本次客户发现任务 ID |
| entry_mode | discovery 或 direct_target；后者不强制搜索十家 |
| snapshot | 对象：revision、company、industry、products、markets、customer_types、cooperation_objective、keywords、profile_confirmation、keyword_confirmation |
| snapshot.revision | 本次不可变配置修订 ID；有实质改变就新增修订 |
| snapshot.keywords | 对象：include 非空词列表、exclude 词列表、provenance 推荐/自定义来源；不要求固定词组 |
| 确认对象 | confirmed 布尔值、revision、basis 非空实际确认依据、confirmed_at 可空的真实时间 |
| batches | 对象列表：id、kind、requested_count、quantity_basis、actual_count、candidate_ids、snapshot_revision、shortfall_reason |
| candidates | 对象列表：id、name、country、website 可空、match_reason、sources、entity_key、status、snapshot_revision |
| candidate.sources | 实际读取的来源记录列表，每项 url、access_state=read、checked_on；合成记录仍必须声明 synthetic=true |
| entity_key | 当前任务内的规范实体标识；实体去重依据不只依赖域名 |
| status | pending、selected、excluded；展示后未选不等于已排除 |
| selection | 本次选择的候选 ID 列表；不代表最终批准 |
| approval | null，或对象 id、candidate_ids、snapshot_revision、basis、confirmed=true、confirmed_at |
| runs | 对象列表：run_id、candidate_id、snapshot_revision、execution、pause；不包含完整研究报告 |
| execution | not_started、running、completed、partial、blocked、stopped |
| pause | null，或 reason_code、reason、conflicts、needed_input、resume_condition |
| approval_history | 历史批准对象列表；保留，不自动授权当前 selection |

本轮字段描述是校验契约，不是用户必须逐项手填的问卷。宿主根据真实交互生成记录；无法证实的字段保持未知。未知官网为 null；不可为了通过结构检查捏造来源。

新客户研究记录增加 gate 对象，包含 schema、discovery_id、candidate_id、snapshot、approval。新流程的每个 run 必须使用获准快照，不能只复制当前最新画像。

- [ ] **Step 4：实现纯校验。**

~~~python
from urllib.parse import urlsplit

def normalize_domain(url):
    if not url:
        return None
    try:
        host = urlsplit(url).hostname
    except (ValueError, TypeError):
        return None
    if not host:
        return None
    host = host.lower().rstrip(".")
    return host[4:] if host.startswith("www.") else host

def valid_quantity(value):
    return type(value) is int and value > 0
~~~

validate_discovery 按类型→配置→批次→候选顺序校验；类型失败返回诊断，不发生 KeyError/TypeError。确认和 true 状态使用 is True，不接受字符串 "true"。读取输入不得写入或自动修复任何字段。

追加批次只接受 quantity_basis="operator"。首批默认 requested_count=10；明确操作人指定首批其他数量时 quantity_basis="operator" 可用，默认仍是十家。direct_target 不要求批次，但仍要求候选与配置确认。

去重以 candidate ID、entity_key 为硬检查；normalize_domain 只检测潜在重复。共享域名并不硬删除，宿主需核对公司/国家/实体。重复 entity_key 或重复 ID 在不同批次不能通过。未知官网不报“客户不存在”。

~~~python
"""Validate declared discovery records; no search, authorization or sending."""
import argparse
import json
from pathlib import Path
from discovery_contract import validate_discovery

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("record", type=Path)
    args = parser.parse_args()
    try:
        data = json.loads(args.record.read_text(encoding="utf-8-sig"))
        issues = validate_discovery(data)
    except (OSError, ValueError, TypeError) as exc:
        issues = [{"code": "INPUT_ERROR", "detail": str(exc)}]
    print(json.dumps(
        {"model_version": "2.0.1", "issues": issues},
        ensure_ascii=False, indent=2
    ))
    return 1 if issues else 0

if __name__ == "__main__":
    raise SystemExit(main())
~~~
